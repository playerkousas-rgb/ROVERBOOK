# ROVERBOOK · 樂行童軍紀錄冊

一本藍色布面、逐頁對應紙本的電子紀錄冊。打開就是封面，翻開後每一頁就是紙本的第 n 頁；
點一下任何一行就可以打字，字多會自動縮小，也可以放大輸入；領袖可即場簽名。

- **毋須登入**：沒有帳號、沒有密碼，資料留在你這部裝置。
- **逐頁對應**：43 頁（含封面第 1 頁及第 42–43 頁空白頁），與《Rover Scout Record Book（v 20260727）》第 1–43 頁一一對應（另加數位附錄）。
- **點擊即寫**：每條線／每一格都可以直接輸入，字體自動縮到格內；每格亦可放大輸入，整頁可放大 1.4 倍。
- **可核實**：每個細項、服務、獎章、頒發、會面都有審核員／領袖簽名。
- **可分享**：自選章節，生成二維碼或連結；隨時作廢。
- **為手機而生**：單欄大字、表格變卡片、拇指位翻頁、輸入自動避開鍵盤。
- **可帶走**：加入手機主畫面（建議）、A4 列印、JSON 備份、ROVERBADGE 進度交換。

> 原型示範，非香港童軍總會官方系統。訓練綱要對應 2026 第五版（32 細項）。

## 2. 填寫方式

- **點一下**任何底線／方格 → 即刻變成輸入框，可以打字；失焦即儲存。
- **自動縮字**：字數超出格線時字體會逐步縮小（最小 7px），保持一行／固定高度，不會撐爆版面。
- **放大**：每格右上「⤢」→ 彈出大字輸入框（Enter 完成、Esc 取消）；頂部「放大」可整頁放大 1.4 倍。
- **勾選細項**：左方可勾，日期預設今日，亦可自行改；旁邊填審核員姓名。
- **手寫**：每一格除了打字，都可以切換「手寫」用指尖書寫（輸入面板右上 `打字 / 手寫`）。墨跡以圖片保存，會**等比縮到格線內**（唔會斷字、唔會撐爆），亦可以再放大看或重寫。
- **手寫會自動壓縮**：儲存前縮到 ≤640×120 單色，一張約 1–3KB（原本可能要 20KB）。所以「能保就保」；真的空間不足時，可在附錄一按**只保留簽名（清除頁面手寫）**，文字與簽名不會受影響。
- **簽名**：持有人、團長、管理委員會主席、審核員、區／地域總監、續會，全部用手寫板（手指或觸控筆）；簽名同樣按格位等比縮放，三張申請表會直接取用同一幅墨跡。
- 每次修改自動儲存（localStorage：`roverbook.book.v3`，會自動接手舊版 v2 資料）。

## 3. 手機模式（把電話變成紀錄冊）

- 每頁自動由 A4 版面變成**單欄長頁**：文字 14px、標題 21px、行高 1.75，唔需要放大都睇得清。
- 所有表格自動變成**一張張卡片**，每格上方有細字欄名（日期、地點、審核員…），唔會擠成一條線。
- 欄位 label 在上、輸入在下，整行 32px 高；輸入時字級 16px（避免 iPhone 自動放大），並自動捲到畫面中央避開鍵盤。
- 頁首頁碼會黏在頂部；底部是拇指位的翻頁列（上一頁／頁數／下一頁），亦可以左右滑。
- 章節左邊有顏色書邊：會員章綠、肩章藍、獎章金、貝登堡紅，揭到邊就知。
- 封面有「繼續上次 · 第 n 頁」，唔需要每次由第一頁揭起。

### 列印

- 文件頂部「**列印 / 存 PDF**」即列印；「**全部三張**」（`/forms/all`）一次過印 PT/69、PT/21、PT/22，每張由新一頁開始。
- 「**預覽**」＝所見即所印：螢幕上先隱藏所有介面、還原 1:1（A4 闊度），確認排版後才按列印。
- 已設 A4、8mm 邊界；列印時頂欄、按鈕、提示、頁尾全部唔會出現，只出文件。
- 手寫墨跡、簽名、近照以圖片列印，保持比例；表格線、灰底標題會保留顏色。
- 列印方法：電腦 ⌘P／Ctrl+P（可揀「另存為 PDF」）；iPhone 分享 →「列印」；Android ⋮ →「列印」。
- `PT/*.pdf` 原稿仍以總會版本為準；本表格依照 8/2026 版欄位重排，遞交前請核對一次。

## 6. 二維碼傳送與領袖核簽（成員 ⇄ 領袖）

唔需要伺服器、唔需要名單：成員出示一隻二維碼，領袖用 Chrome 掃，即刻看到對方剔選的內容。

**成員（出示）**

- 選單 →「出示二維碼（給領袖掃描）」，或附錄頁同一粒按鈕。
- 逐項剔選：個人資料、聯絡方法、訓練進度、活動簡述、頒發／會面紀錄、領袖簽署、持有人簽名、近照。
- **預設一個都唔會放入**；每次出示都要重新剔，剔幾多、看幾多。
- 畫面會顯示用量（字元數／2,400）及是否已壓縮；超出容量會即時提示取消「近照」或「簽署」。
- 相機用不到時，成員可「複製內容」，領袖貼上亦可（`RB1…` 開頭）。

**領袖（掃描）**

- 選單 →「領袖模式：掃描成員紀錄冊」（`/scan`）→ 允許相機 → 對準二維碼。
- 讀取後即跳到唯讀檢視：封面、個人資料、訓練進度（逐項日期及審核員）、活動簡述、簽署。
- 資料只留在這部手機的該次瀏覽（sessionStorage），關閉瀏覽器即消失，**不會上傳任何地方**。

**領袖核簽（回傳碼）**

1. 領袖掃入成員 QR → 畫面出現「領袖核簽」面板，列出有日期的項目，預設勾選**未簽名**的。
2. 按「以領袖身分簽名」簽一次（套用到所選項目），再產生回傳碼。
3. 成員用 `/scan` 掃回傳碼 → 顯示「舊 → 新」對照（日期、審核員）及日期不同的提示 → 按「寫入我的紀錄冊」。
4. 只會更新有核簽的項目；其他內容、成員原有的日期與簽名不會被覆蓋。同一張核簽單有編號（`seq`），重複掃入會被提示。

- 回傳碼＝**一張領袖簽名**（壓縮至 320×96 單色 PNG）＋項目清單，所以 6 項只需約 810 字元；10–20 項仍可放一隻 QR。
- 項目太多時會自動改為「不附簽名圖」；仍然超標就提示分兩次核簽。
- 核簽屬於信任制（紙本簽名同等性質），唔係防偽憑證。

**容量與技術**

- 一隻 QR（version 40、L 級）約 2,953 bytes；本程式以 2,400 字元為安全上限，資料會先用 gzip 壓縮。
- 實測示範紀錄冊：個人資料＋進度＋簡述 ≈ 1,330 字元，一隻 QR 足夠；加上近照／簽名會超標。
- 掃描優先用瀏覽器內建 `BarcodeDetector`（Chrome／Android），不支援時自動改用內建 `jsQR`（iPhone 的 Chrome／Safari 一樣可掃）。
- 必須以 `https://` 開啟（Vercel 預設已是），並允許相機權限。

## 8. 與 ROVERBADGE 的定位（BOOK ≠ BADGE）

| | ROVERBOOK（本書） | ROVERBADGE（後端） |
| --- | --- | --- |
| 定位 | 成員**帶出街**的紀錄冊 | 領袖的**紀錄與管理** |
| 主要用戶 | 樂行童軍本人 | 領袖、旅部 |
| 視角 | 一本書，逐頁寫、逐項簽 | 全旅／全支部一覽，一次過看與簽所有成員 |
| 資料 | 本機（localStorage）＋二維碼 | 匯入／匯出、接入支部系統 |
| 離線 | 完全可運作 | 需要資料來源 |

- 兩者**不互相依賴**：冇 BADGE，BOOK 一樣完整；冇 BOOK，BADGE 一樣運作。
- 連接只經**介面**（schema），唔會直接讀對方資料庫：
  - `roverbook/record@1`（QR 傳送，已有）
  - `roverbook/signoff@1`（核簽單，已有）
  - `roverbadge.progress.v2`（建議：加審核員、支部前綴 code、簽核狀態）
- 建議 **item code 帶支部前綴**（`RS-L3-LEADER-01`），日後 5 個支部合併才不會撞。
- 建議單一權威來源：每個項目只有一邊可以「簽」，另一邊只收快照（避免雙向同步衝突）。
- 5 個支部各有自己的 BOOK（同一引擎、不同 profile）；BADGE 負責彙總。

## 9. 儲存健康與容量

- 紀錄冊存喺瀏覽器 `localStorage`（每部機大約 5MB，以 UTF-16 計即約 250 萬字元）。
- 附錄頁新增「**儲存健康**」卡：已用百分比、最佔空間的三項、一鍵**壓縮圖片／墨跡**、**匯出備份**、以及**只保留簽名**。
- 儲存失敗（例如爆 quota 或私人模式封鎖）時：頂欄會顯示「未儲存」，並出現紅色提示條叫你壓縮或匯出 —— 唔會再靜靜咁失效。
- 建議每隔一段時間匯出一次備份（JSON），換機或清理瀏覽器資料時可完整還原。

## 10. 離線使用（PWA）

第一次**連網**開啟之後，app 外殼（HTML／JS／CSS／圖示）會由 service worker 存落手機；之後**飛機模式都用得**。

- 離線可以做：逐頁填寫、手寫、簽名、生成三張官方表格、「預覽」及列印／存 PDF、掃描二維碼（相機唔需要網絡）。
- 離線做唔到：建立分享連結（需要伺服器）——但日常核對用二維碼即可。
- 開啟方式：iOS Safari／Chrome「分享 → 加入主畫面」；Android Chrome「安裝應用程式」。用主畫面圖示開啟即為全螢幕。
- **更新**：每次開 app 或回到前景會檢查新版本；一有更新會彈「有新版本 / 重新載入」，唔會長期停留在舊版。
- 快取策略：`/assets/*`（有 hash）用 cache-first；頁面導航用 network-first，失敗才用快取；`/api/*` 完全唔經快取。
- 開發者：改版時把 `web/public/sw.js` 的 `VERSION` 加一，`activate` 會清走舊 cache。

**驗證方法**：開一次網站 → DevTools → Network → 勾 Offline → 重新載入，應該照開、照填、照列印。

## 12. 列印與「對回 PDF 頁數」

## 19. 開始使用

```bash
npm install
npm run dev      # http://localhost:3001
npm run smoke    # 108 項：封面、43 頁逐頁、填寫／手寫／壓縮／簽名、三張表格、整本列印對頁、二維碼傳送、領袖核簽、儲存健康、離線／更新、分享、API
npm run build && npm start
```

環境變數：`PORT`（預設 3001）、`PUBLIC_BASE_URL`。

### 部署到 Vercel

repo 已附 `vercel.json`：`npm run build` → `dist`，所有路徑 rewrite 到 `/index.html`，所以 `/p/...`、`/forms/...` 直接開都唔會 404。

- Vercel 上係**純靜態、零後端、零按人頭成本**：紀錄冊資料只存喺各人自己部機，你唔需要為每個旅團準備資料庫或儲存空間。
- 換機／換瀏覽器要先用「匯出備份」再「匯入」。
- 分享連結、QR 需要 Node 伺服器（`npm start` 或自行部署 `server/`）先有 `/api`；靜態部署時呢幾粒掣會報錯，其餘功能不受影響。
- 部署後建議即試：`/forms/pt21` →「預覽」→「列印」；`/scan`（相機需要 HTTPS，Vercel 已提供）；以及**離線測試**（第一次開完 → 開飛機模式 → 重新載入）。
