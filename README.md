# ROVERBOOK · 樂行童軍紀錄冊

一本藍色布面、逐頁對應紙本的電子紀錄冊。打開就是封面，翻開後每一頁就是紙本的第 n 頁；
點一下任何一行就可以打字，字多會自動縮小，也可以放大輸入；領袖可即場簽名。

- **毋須登入**：沒有帳號、沒有密碼，資料留在你這部裝置。
- **逐頁對應**：41 頁，與《Rover Scout Record Book（v 20260727）》第 1–41 頁一一對應（另加數位附錄）。
- **點擊即寫**：每條線／每一格都可以直接輸入，字體自動縮到格內；每格亦可放大輸入，整頁可放大 1.4 倍。
- **可核實**：每個細項、服務、獎章、頒發、會面都有審核員／領袖簽名。
- **可分享**：自選章節，生成二維碼或連結；隨時作廢。
- **可帶走**：加入手機主畫面（建議）、A4 列印、JSON 備份、ROVERBADGE 進度交換。

> 原型示範，非香港童軍總會官方系統。訓練綱要對應 2026 第五版（32 細項）。

## 2. 填寫方式

- **點一下**任何底線／方格 → 即刻變成輸入框，可以打字；失焦即儲存。
- **自動縮字**：字數超出格線時字體會逐步縮小（最小 7px），保持一行／固定高度，不會撐爆版面。
- **放大**：每格右上「⤢」→ 彈出大字輸入框（Enter 完成、Esc 取消）；頂部「放大」可整頁放大 1.4 倍。
- **勾選細項**：左方可勾，日期預設今日，亦可自行改；旁邊填審核員姓名。
- **簽名**：持有人、團長、管理委員會主席、審核員、區／地域總監、續會，全部用手寫板（手指或觸控筆）。
- 每次修改自動儲存（localStorage：`roverbook.book.v3`，會自動接手舊版 v2 資料）。

## 3. 分享與私隱

11 組內容逐項勾選，建立唯讀快照（`/v/:id`）＋二維碼；刪除金鑰留在本機，只有成員可作廢連結。
更新內容會產生新連結，舊連結即時失效。未勾選的聯絡資料會在伺服器端清空。

## 4. 放入手機（你揀的 A 方案）

**加到主畫面，今日就用，零成本、毋須憑證。**

1. iPhone：用 **Safari** 開本頁 → 底部「分享」→「加入主畫面」→「新增」。
2. Android：用 **Chrome** 開本頁 → 右上三點 →「安裝應用程式」／「加到主畫面」。

之後主畫面會有 ROVERBOOK 圖示，一按即開、全螢幕、毋須登入；填寫、簽名、分享、列印全部照用。

Apple / Google Wallet pass 是**額外、可選**的（Apple 要 US$99 開發者帳戶；Google 要開通 Issuer）。
App 內「錢包」對話框已把這段寫成非技術語言，並會老實顯示「欠幾項」，不會假裝成功。

```
# 只有真的要做 Wallet pass 才需要（管理員層面）
APPLE_PASS_TYPE_ID / APPLE_TEAM_ID / APPLE_PASS_CERT_P12 / APPLE_PASS_CERT_PASSWORD / APPLE_WWDR_P12
GOOGLE_WALLET_ISSUER_ID / GOOGLE_WALLET_SA_JSON / GOOGLE_WALLET_CLASS_ID
PUBLIC_BASE_URL
```

## 5. 與 ROVERBADGE 互通

同一套 `L1…L4` 項目編號（32 細項，綱要第五版）。訓練頁或附錄可匯出 ROVERBADGE 相容 JSON；
匯入時先配 YMIS、再配姓名，不會覆寫本機已有的日期與簽名。只交換「項目 + 日期」，不交換簽名。
部分紙本細項（例如禮節 3.2）在綱要中併入同一項，電子版會同步標記同一組細項。

## 6. 開始使用

```bash
npm install
npm run dev      # http://localhost:3001
npm run smoke    # 65 項：封面、41 頁逐頁、填寫／放大／簽名、分享、API、Wallet 501
npm run build && npm start
```

環境變數：`PORT`（預設 3001）、`PUBLIC_BASE_URL`。

## 8. 已知限制

- 資料在 localStorage；清除瀏覽器資料會失去，請定期匯出備份。
- 自動縮字是版面效果，不是無限容量：極長文字仍建議用放大輸入查看。
- 紙本制服頁是圖版，電子版以文字＋備註代替，未收錄原圖。
- 簽名是筆跡圖像，不是 PKI 數碼簽章。
- 綱要為 2026 第五版，官方更新時請自行核對。
