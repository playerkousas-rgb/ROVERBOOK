# ROVERBOOK · 樂行童軍電子紀錄卡

把《香港童軍總會樂行童軍紀錄冊》由一本 43 頁的紙本／PDF，變成每位成員口袋裡的一張卡。
成員擁有自己的卡，自選分享哪幾項資料；領袖像加朋友一樣送出請求，成員批准後才讀得到，亦可隨時收回。

> 這是一個可運作的原型（prototype），資料為示範資料，並非香港童軍總會官方系統。
> 紀錄冊的章節結構參考《Rover Scout Record Book (v 20260727)》。

---

## 1. 為何不是把紙本轉成 PDF

| | 紙本 / PDF | ROVERBOOK |
|---|---|---|
| 攜帶 | 43 頁，要整本帶 | 一張卡、一個 QR |
| 更新 | 印了就不能改，要靠蓋章 | 即時更新，領袖即時看到 |
| 分享 | 整本交出去，無法選擇 | 逐項欄位授權，可只給基本資料 |
| 核實 | 手寫簽名、蓋旅印 | 領袖數碼核實，附日期與簽署人 |
| 紀錄冊有效期 | 要翻到最後一頁查 | 卡片正面直接顯示「有效至」 |

## 2. 功能

**成員**
- 電子卡：Apple Wallet 風格，正面是身份＋會籍＋七項考驗進度，背面是分享 QR。
- 紀錄冊：個人資料、童軍經歷、七項考驗、服務、獎章、遠足／海外、其他經驗、續會。
- 私隱中心：23 個資料欄位 × 3 個可見級別，7 個紀錄章節獨立設定，另設「保守／標準／開放」快速預設。
- 連結審批：看到對方的姓名、團籍及請求原因，可選擇「只分享已連結資料」、「授予全部資料」或拒絕。
- 動態紀錄：誰看過我的卡、誰要求過、誰核實過，一律可查。
- 分享：公開頁面（`/c/<slug>`）、QR、複製連結、一鍵更換連結（舊連結即時失效）、列印／存 PDF。

**領袖**
- 工作台：已連結成員、全部資料授權數、續會到期、平均訓練進度。
- 搜尋成員（會員編號／姓名）→ 送出連結請求 → 等待批准。
- 讀取成員卡片：只看到成員批准的範圍，未分享的部分以「未分享」呈現，不會假裝空白。
- 行動：辦理續會、簽署紀錄冊、核實考驗／服務／獎章（需「全部資料」授權）。

## 3. 私隱模型

每項資料可以獨立設定三種可見度：

| 級別 | 誰看得到 | 用途 |
|---|---|---|
| 公開 Public | 任何取得你分享連結的人（毋須登入） | 姓名、團籍、公開的獎章 |
| 已連結 Linked | 你批准過的領袖／伙伴，經登入後讀取 | 聯絡電話、訓練進度、服務紀錄 |
| 只限自己 Private | 只有你，以及你授予「全部資料」的領袖 | 出生日期、地址、緊急聯絡人 |

另外，成員可以就個別領袖把權限由「已連結資料」升级為 **全部資料**（包括私人欄位），亦可隨時降級或解除連結。
所有讀取、請求、核實、續會都會寫入該成員可見的動態紀錄。

實作要點（`server/access.js`）：

- 每一次讀取都由伺服器按 `viewer × subject × connection` 重新計算可見欄位，回傳的 payload **只包含** 該名 viewer 有權看到的內容；前端不會收到被隱藏的資料。
- 隱藏欄位、未分享章節只回傳「有幾項」或「未公開」，不會回傳內容。
- 會籍狀態、訓練進度等衍生資料同樣受章節可見度控制。
- 公開連結只投影「公開」級別，成員更換 slug 後舊連結即時失效。

## 4. 快速開始

```bash
npm install
npm run dev          # http://localhost:3001（Vite middleware + Express 同一端口）
```

生產模式：

```bash
npm run build
npm start            # NODE_ENV=production，Express 直接服務 dist/
```

首次啟動會自動建立 `data/db.json`（已加入 `.gitignore`），內含示範資料。刪除該檔即可重置。

## 5. 專案結構

```
shared/schema.js        欄位、章節、七項考驗、四個獎章、預設私隱（前後端共用）
server/
  index.js              Express + Vite middleware（開發單端口）
  api.js                所有 REST 端點
  access.js             私隱投影引擎：buildCard / miniCard / 權限等級
  store.js              JSON 檔案儲存 + 示範資料
web/src/
  App.jsx               外殼、導航、路由
  components/Card.jsx   電子卡（可翻轉）與權限提示
  pages/                Login / Home / RecordBook / Privacy / Connections / Crew / MemberView / PublicCard
  ui.jsx                設計系統元件（Icon、Chip、Segmented、Modal…）
scripts/smoke.mjs       jsdom 全畫面煙霧測試
data/db.json            執行時資料（不納入版本控制）
```

## 6. API 摘要

| Method | Path | 說明 |
|---|---|---|
| POST | `/api/login` · `/api/logout` | 會員編號 + PIN，HttpOnly session |
| GET | `/api/me` | 自己的完整資料 + 卡片投影 |
| PUT | `/api/me/profile` · `/api/me/privacy` | 更新個人資料 / 逐項私隱 |
| POST | `/api/me/records/:section` · DELETE `.../:id` | 新增／刪除紀錄（服務、獎章、遠足…） |
| POST | `/api/me/training/:componentId` | 標記七項考驗 |
| POST | `/api/me/share/rotate` | 更換公開連結 |
| GET | `/api/connections` · POST `/api/connections/request` | 連結列表／請求 |
| POST | `/api/connections/:id/respond` · PATCH · DELETE | 批准（可選範圍）／改權限／解除 |
| GET | `/api/card/:id` | 按 viewer 權限投影的卡片 |
| GET | `/api/public/card/:slug` | 公開卡片（毋須登入） |
| GET | `/api/directory?q=` | 搜尋成員／領袖 |
| GET | `/api/leader/overview` | 領袖工作台 |
| POST | `/api/members/:id/verify` · `/renew` | 核實考驗／獎章／簽署 · 續會 |
| GET | `/api/me/audit` | 我的讀取紀錄 |
| GET | `/api/qr.svg?d=` | 產生 QR（SVG） |

## 7. 紀錄冊 → 資料模型

| 紀錄冊 | ROVERBOOK |
|---|---|
| 個人資料（相片、編號、姓名、出生日期、地址、電話、血型、緊急聯絡人） | `profile` + 逐欄私隱 |
| 旅部資料（主辦機構、旅長、團長、集會地點、入團日期） | `profile.group` 群組 |
| 童軍紀錄（小童軍 → 樂行童軍） | `scouting[]` |
| 轉旅／改地址／改資料 | 由成員自行更新，保留動態紀錄 |
| 會員資格續期（每年 1 月 1 日至 12 月 31 日） | `renewals[]`，由領袖簽署 |
| 服務紀錄 | `service[]`，可被領袖核實 |
| 獎章及獎勵 | `awards[]` + 四個漸進獎章 |
| 訓練計劃（會員章 → 肩章 → 獎章 → 貝登堡獎章） | `training.badges` |
| 七項考驗（準領袖培訓、童軍技能、服務、國際視野、興趣及技能、身心健康、挑戰） | `training.components` |
| 其他經驗、遠足及海外活動 | `additional[]`、`expeditions[]` |
| 制服 | 未收錄（屬參考資料，非個人紀錄） |

## 8. 設計取捨

- **卡片先於表單**：首頁是一張卡，不是一本書。需要細節時才進入「紀錄冊」分頁。
- **批准才有資料**：連結未批准時，領袖只看到公開欄位，並明確顯示「5 項未分享」，避免誤以為成員沒有紀錄。
- **雙層授權**：欄位級可見度（公開／已連結／私人）＋ 關係級範圍（已連結資料／全部資料）。成員可以「對所有人開放電話，但只對團長開放全部資料」。
- **伺服器端投影**：前端不接收無權限的資料，避免「介面隱藏、網絡仍可讀」的假私隱。
- **可撤回**：更換連結、降級權限、解除連結即時生效，並留下紀錄。

## 9. 上線前要處理

1. **身份**：接上香港童軍總會會員系統／SSO，取代示範 PIN（示範資料庫以明文儲存 PIN，只為方便試用，切勿用於真實資料）。
2. **資料庫**：把 `server/store.js` 換成 PostgreSQL（成員、連結、紀錄、審計日誌分表），加行級權限。
3. **檔案**：相片改存物件儲存（S3／GCS）＋簽名 URL，不放在 JSON。
4. **合規**：按香港《個人資料（私隱）條例》寫私隱政策、資料保留期、家長同意（18 歲以下）、查閱與改正機制；加入稽核匯出。
5. **核實機制**：領袖簽署應使用不可否認的簽章（例如總會憑證），而非單一欄位。
6. **離線／錢包**：PWA 快取卡片；研究 Apple Wallet / Google Wallet pass（.pkpass）作實體卡替代。
7. **無障礙與 i18n**：現時以繁體中文（香港）為主，英文欄位並列，可加完整英文介面。

## 10. 測試

```bash
npm run dev      # 另一個終端
npm run smoke    # 以 jsdom 渲染所有畫面，檢查崩錯、缺漏內容
npm run build    # 生產建置
```

`scripts/smoke.mjs` 會以成員及領袖身份登入真實 API，逐頁渲染登入、我的卡片、紀錄冊、私隱、連結、領袖工作台、成員卡片及公開卡片。
